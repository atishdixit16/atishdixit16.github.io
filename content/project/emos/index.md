Electronic materials discovery increasingly depends on a combination of databases, physics-based simulations, property prediction models, and generative models. However, these resources are often developed independently, making it difficult to connect them into coherent and reusable discovery workflows.

The Electronic Materials Ontology System provides a modular framework for bringing these capabilities together. It uses a shared vocabulary for material properties and standardised data contracts so that researchers can combine different databases and models without rebuilding the connections between them for every project.

By supporting custom workflows, the framework helps researchers move from material search and property prediction to candidate generation and device-oriented design. Its contribution model also makes it easier for the community to extend the system with new data sources, models, and discovery capabilities.
